# Super-Store-Sales-Analysis
Analyzed SuperStore transactional sales data using Power BI to evaluate sales and profitability across products, regions, customers, and time; built interactive visualizations and derived business insights to support data-driven decision-making.


**Overview**
A Power BI sales analytics project using the SuperStore Sales Dataset to analyze sales and profitability across products, customers, regions and time.

**Objectives**
Analyze sales and profit performance

Identify high- and low-performing business areas

Study trends over time

Compare categories, regions and customer segments

Present findings through an interactive Power BI dashboard

**Tools**
Power BI

Power Query

DAX

CSV

Data Visualization

**Workflow**
Import the sales dataset

Inspect and clean the data

Transform data using Power Query

Create analytical measures using DAX

Build visuals and dashboard pages

Analyze business performance

Present actionable insights
